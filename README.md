# TypingVibes
A Windows application that converts typing speed into vibration via Buttplug.io and Intiface.

# Guide
To use the app, simple start it up along with Intiface central and connect your toy to Intiface.
Then head over to the device settings tab and click the connect button to connect to Intiface and your toy. 
Once that is done click "Enable Keyboard monitoring" and adjust the values to you liking then start enjoying your increase productivity!
